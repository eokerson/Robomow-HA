# Changelog

All notable changes to this project will be documented in this file.

## [Unreleased]

## [0.3.0] - 2026-06-18

- Updated translations
- Changed next departure sensor from duration (minutes) to timestamp
- Renamed previous departure sensor to previous duration
- Removed mower home and charging active binary sensors

## [0.2.0] - 2026-06-14

- Updated to robomow_ble 1.2.0
- Updated dependencies
- Updated translations
- Disabled Dependabot push requests
- Fixed lint for shebang without being executable
- Added manifest version check script (`check_manifest_version.py`)
- Added manifest version validation to lint process

## [0.1.0] - 2026-06-06

- Initial release
- Updated README
- Updated lint configuration
